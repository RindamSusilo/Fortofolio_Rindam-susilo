# Portfolio Rindam Susilo

## Isi project
- `index.html` — struktur halaman
- `style.css` — desain dan responsive layout
- `script.js` — menu mobile dan tahun footer

## Cara menjalankan
1. Buka `index.html` di browser.
2. Untuk GitHub Pages, upload ketiga file ke repository.
3. Jika tugas meminta branch baru, buat branch misalnya `portfolio` sebelum push.

## Yang perlu diganti
- Link GitHub/Instagram/LinkedIn di `index.html`
- Email
- Deskripsi diri
- Daftar project
- Foto profil jika ingin menggunakan foto asli
